## Notes

### `tool_and_forced_tools`

Direct-client tool_calls works; SDK native Agent.run with forced_tools fails on the Pollinations free tier (HTTP 402, 1 reply / 45 s / IP). See docs/WHAT_WE_LEARNED.md.

### Honest limitation

The SDK-native `Agent.run` path against the Pollinations free tier is unreliable in two different ways. Usually it fails with HTTP 402 (`1 reply every 45 seconds per IP`): one native turn fires several consecutive model calls, the first consumes the quota, and the SDK's hardcoded 300 ms retry backoff cannot wait out a 45 s window. On the rare run where the turn survives the rate limit, the reply may still be prose (observed in full-probe runs on 2026-11-16) instead of structured output, and fail Pydantic validation. Probes that need a live native turn are therefore marked `partial`/`fail` with the actual reason, and the production path uses the direct HTTP client (one call per step, paced ≥45 s). See `docs/WHAT_WE_LEARNED.md`.
